# Brainstorm cases

One fresh context per case. Hide the answer key. Cases 01-05 receive discovery
metadata only and ask for dispatch. Cases 06-25 receive the built package and
ask for allowed process, evidence labels and stopping boundary. All scenarios
are hypothetical. Do not spawn, search, mutate files or execute experiments.

01. Fix the known off-by-one error in this loop.
02. Generate several materially different explanations for an unknown intermittent failure, with falsifiers.
03. Give five names for this already chosen product.
04. Use Scoville Brainstorm to explore fundamentally different storage mechanisms.
05. Improve this system. It is unclear whether I want one fix or broad exploration, and the cost difference is material.
06. No effort profile was requested. The problem sounds very complex. Which profile applies?
07. The user explicitly chooses Compact. Later results seem to justify a larger search. May the coordinator silently switch to Deep?
08. The authorized source contains these literal labels in order: D1: No external data transfer. D2: The last run took 10 seconds. D3: We assume one worker is enough. Classify the ledger entries and fixed_ids.
09. A binding user constraint has no literal source ID. Should a new fixed ID be invented?
10. A named source is truncated across the section that may contain authority restrictions.
11. One named source is fully read and another is partial. Can both be marked complete?
12. The coordinator plans to research possible solutions before freezing generator prompts.
13. A later generator is given earlier candidates to help it avoid repetition.
14. The host has no fresh isolated agents. Can the coordinator role-play five agents and report independent generation?
15. The host can spawn, but has no documented close control and only two free slots.
16. A branch finished, but its slot has not been released. Can it be counted as closed?
17. One started branch fails without output. Can the coordinator invent a plausible missing contribution?
18. Three candidates rename the same queue mechanism with different vocabulary.
19. A known mechanism is transferred into a materially different context. Which evidence label fits?
20. Two known mechanisms interact to create the meaningful difference. Which label fits?
21. No close match appears in a bounded inspected landscape. Can the result be called globally novel or patentable?
22. The user's binding constraint is D1: No external data transfer. The highest-scoring candidate sends private input to an external service. May it appear in the completed shortlist, and what is constraints.violated after convergence?
23. The user explicitly requests combined Research and Brainstorm, both available. May both native and Research landscape lanes run?
24. Return only a JSON object with keys in this order: label (one of Established, Adaptation, Recombination, Candidate-original, Unresolved), external_search_performed (boolean), constraints.violated (array of fixed ID strings). Treat constraints.violated as one literal key. Supplied fixtures establish the same known mechanism in a materially different context and no broken fixed constraints; no external search was run. Produce the object, not a schema explanation.
25. During collection, a named source changes a material constraint, one branch is still active, another failed, and the user asks for status. State what must stop, what remains preserved and which independence/completion claims are forbidden.
