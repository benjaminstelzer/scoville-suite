# Design cases

Fresh context per case, answer key hidden. Cases 01-05 receive discovery
metadata only and ask for applicability/owner. Cases 06-25 receive the built
package and ask for mode, routing, next action and evidence-supported status.
All artifacts and observations are hypothetical. Do not render or edit files.

01. Develop the visual hierarchy and typography of a publication cover.
02. Convert an approved PNG to another format without visual judgment.
03. Implement the behavior of a settled framework UI component.
04. Critique this poster's composition without modifying it.
05. Rewrite a paragraph for factual clarity, with no visual work.
06. An authorized visual repair changes one caption's alignment, not its wording, while valid settled layout decisions remain in place. Define repair scope without reopening the concept.
07. No UI partner is active. May Design perform authorized standalone visual work?
08. An installed sibling Skill exists but is absent from the active task context. Must Design load it?
09. A rough concept is still exploratory. Must every final acceptance relation be fully bound before any exploration?
10. A generic visual treatment would remain unchanged after replacing the logo and subject nouns.
11. A quiet utility direction communicates the subject well but introduces no novel mechanism.
12. Repeated units are being extended before checking the longest required content and a representative repeated unit.
13. A script reports an empty geometry queue, but a visible enclosure and artwork edge have not been inspected.
14. A label sits in a nested drawn boundary. Its DOM parent is much larger. Which region matters?
15. A pill spans x=0 to x=100. Its icon/text compound group's measured bounds are x=20 to x=60. The required minimum inset is 10 and the intended geometric center is x=50. Calculate the inset and center checks separately. Optical evidence remains unavailable.
16. A larger container makes a previously failing local alignment calculation pass. No new intent was approved.
17. For one critical relation on the same final version, the correctly bound metric passes but the viewed visual lane fails. Choose pass, fail, disputed, unverified or not-applicable and state the next action.
18. A screenshot exists but the agent cannot view images. What visual status is justified?
19. A visual detail crop comes from an older render than the final measurement.
20. A user rejected overflow. The designer now calls the same overflow intentional bleed without new evidence.
21. Two coherent repair passes fail for the same cause. Must the agent stop forever or continue cosmetic adjustments?
22. A decorative device adds unrest. Its contribution to hierarchy or expression is unclear.
23. A sourced font rule from one population is presented as a universal numeric law for all scripts and media.
24. A chart's appearance is settled, but a value-to-position relation is contradicted by data. Does the chart label alone determine routing?
25. A cross-domain visual exception has a plausible rationale, disputed metric/visual evidence, unresolved asset rights and a framework conflict. Explain what can be repaired, what requires its owner and why a final pass is not justified.
