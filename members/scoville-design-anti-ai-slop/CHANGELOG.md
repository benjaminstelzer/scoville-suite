# Changelog

## v1.2.9 - 2026-09-22

- Keep Critique read-only. Recommendations do not authorize a repair.
- Load coordination rules only for a partner confirmed active and applicable.
- Route WordPress plugin administration work to the renamed
  `scoville-wordpress-ui-backend-anti-ai-slop` Skill.

## v1.2.8 - 2026-09-20

- Clarify that discovering another family Skill does not activate it, while
  independently authorized work continues and a user opt-out applies only to
  the excluded Skill.

## v1.2.7 - 2026-09-19

- Keep Design available through both implicit and explicit invocation for
  visual definition and judgment, while framework UI implementation and
  WordPress plugin-owned wp-admin pages route to their dedicated Skills.
- Load the direct expert index only when specialist methods are needed instead
  of carrying the complete module list in the core instructions.
- State the complete eight-Skill ownership boundary in suite order.

## v1.2.1 - 2026-09-09

- Require actual image inspection for visual proof. If the artifact cannot be
  rendered or inspected, leave the visual claim unverified.

## v1.2.0 - 2026-09-08

- Put composition foundations in the Core and load specialist methods only for
  the open visual decision.
- Separate exploration, consolidation, and final inspection so early ideas can
  remain provisional.
- Require whole-image and detail inspection together with suitable measurements
  of the same artifact.
- Track critical relations, disputed evidence, and affected neighbours through
  repair without imposing a one-correction limit.
- Expanded typography, icon, object-proportion, stroke, join, layout, and
  comparison guidance across 30 specialist modules.

## v1.1.0 - 2026-09-05

- Added practical construction, comparison, and repair methods across
  typography, colour, identity, imagery, information design, responsive
  composition, and motion.
- Distinguished point, line, and area label placement in cartography.

## v1.0.0 - 2026-09-04

- Added generation, read-only critique, repair, and style-direction modes.
- Added selective routing across 30 visual-design modules, including identity,
  typography, imagery, information design, packaging, and wayfinding.
- Added explicit composition with Scoville UI: Design owns visual direction and
  judgment, while UI owns framework implementation and rendered behavior.
- Kept standalone operation when Scoville UI is absent or inapplicable.
